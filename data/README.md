# Датасет Pharma Decision Workflow

Версия 1.0.0, скопирован 18.10.2026 из пакета `material/part5/` (архив происхождения: отчёт, скрипты генерации, QA-проверки и манифест SHA-256 находятся там).

## Состав

| Папка / файл | Назначение |
|---|---|
| `pipeline/` | 160 сценариев / 20 контекстов — основной тест сквозного процесса решения |
| `tools/` | 75 опубликованных пар совместимости (с метками и без) и 24 контрактные проверки |
| `splits/` | dev 96 / validation 32 / test 32; варианты одного контекста не разделены |
| `evidence/` | 20 предметных + 4 общие карточки источников; реестр источников и наблюдения |
| `examples/` | 12 кейсов согласования — не слепой тест |
| `reference/` | Критерии оценщика (gold) и эталонная логика |
| `schemas/` | JSON-схемы контрактов, включая `benchmark_response` |
| `DATASET_CARD.md` | Карточка датасета: назначение, сбор, ограничения |
| `PROVENANCE_AND_RIGHTS.md` | Происхождение и права |
| `sources.md` | Аннотированный реестр источников |

## Правила работы

1. **Правки датасета — только здесь.** `data/` — рабочая копия проекта; `material/part5/` — замороженный архив происхождения v1.0. Содержательные правки оформлять новой версией в `DATASET_CARD.md` (версия, дата, причина, затронутые кейсы), не перегенерировать поверх согласованных правок.
2. **Правило честной игры.** `reference/` и test-сплит не подавать в контекст тестируемого агента и не использовать для настройки промптов до контрольного прогона. Иначе оценка системы подменяется знанием разработчиком ответов.
3. **Статус разметки** — `draft_for_expert_review` (см. DATASET_CARD): до экспертного согласования это не научный эталон.
