# Этап 5. Проверяемые данные для формуляционного пайплайна

**Версия:** 1.0.0 / 18.10.2026. **Статус:** исследовательский набор для согласования, не клинически валидированный эталон.

Полный анализ находится в [report_stage5.md](report_stage5.md); [реестр источников](sources.md), [карточка датасета](DATASET_CARD.md), [ограничения прав и происхождения](PROVENANCE_AND_RIGHTS.md).

## Что лежит в комплекте

| Набор | Объём | Назначение |
|---|---:|---|
| `data/pipeline/inputs.jsonl` и `.json` | 160 сценариев / 20 контекстов | Основной тест сквозного процесса принятия решения на фиксированных карточках |
| `reference/pipeline_gold.jsonl` | 160 проектов критериев | Только для оценщика, после экспертного согласования |
| `data/tools/formulationde_public75.jsonl` | 75 опубликованных записей | Сверка с авторскими метками совместимости; есть ограничения контекста |
| `data/tools/compatibility_inputs.jsonl` | те же 75, без меток | Вход отдельного классификатора; не использовать файл с метками как вход |
| `data/tools/contract_tests.json` | 24 синтетические проверки | Единицы, конечные точки, неизвестные данные, границы доступа |
| `evidence/cards/` | 20 предметных + 4 общие карточки | Кураторские парафразы первоисточников, не полный текст документов |
| `examples/approval_examples.json` | 12 выбранных кейсов с критериями | Согласование, **не слепой тест** |

JSON и JSONL — две сериализации одних примеров, а не дополнительные наблюдения. 160 — не 160 независимых препаратов. Нет новых реальных экспериментов, пациентских записей и изготовленных рецептур. В архиве нет всех 9982 строк AqSolDB или всех 1105 записей FormulationDE.

## Проверка комплектности

```bash
python -m pip install -r requirements.txt
python scripts/validate_dataset.py
python scripts/run_contract_tests.py
```

Первая команда проверки валидирует структуру, ссылки, разбиение и собственный формальный оценщик. Вторая запускает эталонную логику 24 фикстур. **Они не запускают ваш пайплайн или внешние ADMET-инструменты.**

## Подать один кейс своей системе

```bash
python scripts/load_case.py --case P5-A01-V01 --output /tmp/P5-A01-V01.input.json
```

Полученный JSON содержит вход, разрешённые карточки, наблюдения и идентификаторы. Подключение его к вашему репозиторию выполняется через адаптер; содержимое репозитория на этом этапе не изучалось. Конкретный HTTP endpoint не выдуман.

Не индексируйте весь архив моделью. Каталоги `reference/`, `examples/`, `qa/`, отчёт и файл с размеченными парами не должны попадать в контекст тестируемого агента. `load_case.py` не читает `reference/` и `examples/`. Для имитации 503 тестовый harness отдельно использует `reference/fault_fixtures.json` и подменяет ответ адаптера. Наличие пользовательского описания сбоя само по себе ещё не проверяет обработку реального исключения.

## Проверить ответы

Адаптер вашего пайплайна должен дать одну JSON-строку на кейс по [benchmark_response.schema.json](schemas/benchmark_response.schema.json). Это проекция для сравнения, не замена контракта основного приложения.

```bash
python scripts/evaluate.py --responses /path/to/responses.jsonl --split test --output /tmp/formal_scores.json
python scripts/evaluate_compatibility.py --predictions /path/to/predictions.jsonl --subset published75 --output /tmp/compatibility_scores.json
```

Первые оценки — формальные: наличие кодов, известных ссылок, требуемых разделов и отсутствие запрещённого численного прогноза. Они **не** проверяют научную истинность, содержательную поддержку цитаты и фактическое выполнение инструмента. Для последних нужны эксперт и независимо записанный trace. Нельзя считать слова агента о выполнении доказательством выполнения.

## Разбиение

`dev`: 96 / 12 контекстов; `validation`: 32 / 4; `test`: 32 / 4. Все 8 вариантов одного контекста находятся вместе. Критерии открыты для согласования, поэтому после просмотра тестовых ответов/разметки этот тест не является секретным. До формального сравнения заморозьте согласованную версию и закройте разметку от агентов и разработчиков промптов.

Поднабор совместимости — отдельный внешний challenge, не обучающая выборка. В нём есть paclitaxel, также присутствующий в основном test. Это пересечение учтено как риск: не обучать модель на размеченных 75 парах и затем заявлять независимое качество на этом контексте.

## Воспроизвести сгенерированную часть

```bash
python scripts/build_core.py
python scripts/finalize_data.py
python scripts/create_schemas.py
python scripts/validate_dataset.py
python scripts/run_contract_tests.py
```

Это перезаписывает сгенерированные данные; выполняйте на копии. Фиксированные примеры не требуют случайного seed. Правки эксперта нужно сохранить отдельной новой версией, а не затереть генератором.

## Необязательная загрузка AqSolDB

```bash
python scripts/fetch_aqsoldb.py --out /tmp/aqsoldb_snapshot
```

Скрипт обращается к исходному CSV авторов, проверяет заголовок и 9982 строки, сохраняет байты и SHA-256. В данной среде исходный файл скачать не удалось из-за сетевого доступа; работоспособность сетевого этапа не подтверждена. Он не требуется для уже включённых данных. Данные AqSolDB — свойства молекул, не готовые рецептуры.
