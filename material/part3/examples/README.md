# Синтетические примеры контрактов

Все пять JSON-примеров — искусственные тестовые данные. Препарат, продукт, исследование и вычислительная модель за ними не стоят. Число 1.25 в observation.example.json создано только для проверки типов и связи с локальной фикстурой. Его нельзя использовать как физико-химическое свойство.

`module_result.example.json` демонстрирует частичную проверку состава при неизвестных продукте и дозе. `model_use_assessment.example.json` показывает отказ от количественной оценки, а не проведённую симуляцию.

`content_hash` в примере ModuleResult — SHA-256 канонической JSON-сериализации оболочки без самого поля content_hash (ключи сортируются, разделители `,` и `:`, UTF-8). В реальном продукте алгоритм канонизации должен быть закреплён контрактом; данный способ не объявляется внешним стандартом канонического JSON.
