# absorbix-ai

ИИ-платформа поддержки предэкспериментальных решений по оптимизации всасывания и лекарственной формы препаратов: профиль вещества, диагностика ограничивающего фактора, подбор стратегий с проверяемыми источниками и уровнями доказательности.

> Исследовательский прототип. Не медицинский советчик: платформа не предназначена для назначения лечения, смены препаратов или подтверждения безопасности рецептур.

## Быстрый старт

```bash
uv sync                                # окружение (Python 3.12)
cp .env.example .env                   # и заполнить переменные
uv run scripts/check_local_model.py    # smoke-тест LLM (5 проверок)
```

Проверка в Docker:

```bash
docker compose build
docker compose run --rm check
```

## Локальная модель

Платформа рассчитана на LLM за OpenAI-совместимым API (`OPENAI_BASE_URL`). Тестовая конфигурация — vLLM с Qwen3.8-27B-FP8 на локальном GPU: текстовая генерация и structured output (`response_format: json_schema`) проверяются скриптом из коробки. Секреты живут только в `.env` (в git и Docker-образ не попадают).

## Структура

```
src/        код приложения (заготовка, развивается)
scripts/    проверочные и вспомогательные прогоны
data/       датасет Pharma Decision Workflow — см. data/README.md и data/DATASET_CARD.md
```

Датасет: 160 сценариев / 20 контекстов для сквозной проверки процесса решения, 75 опубликованных пар совместимости, карточки источников с провенансом. Статус разметки — для согласования экспертом; правила использования — в `data/README.md`.
